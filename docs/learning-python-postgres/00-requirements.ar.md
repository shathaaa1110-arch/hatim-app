## ما تقوله المدرسة

الطالب يصمم البيانات وعلاقاتها وملفات schema أو migrations، ويبني API بمنطق الأعمال والتحقق والمصادقة، وواجهة تتصل به وتعالج التحميل والفشل. تسمح الصفحة باللغات والأطر وORM والاستضافة وPostgreSQL المدارة. تمنع الخدمات التي تستبدل الطبقات الأساسية، مثل API تلقائية تصبح هي الخادم، أو خدمة مصادقة جاهزة تصبح نظام الدخول. التخزين المحلي وحده وملفات JSON وحدها لا تكفي. السماح بالـAI في الصفحة يتعلق بأفكار وتصاميم الواجهة، مع تنفيذ نهائي يكتبه الطالب وتصميم في Figma. [المصدر](https://hoblertonschool.notion.site/Portfolio-Project-Technical-Requirements-311204290bfc8076ac82d9867899af46).

خطة الاجتماعات موزعة على 12 أسبوعًا: الفكرة والميثاق، ثم التصميم والوثائق، ثم التنفيذ، ثم التسليم. تتطلب Figma ومعمارية وERD ومخططات تتابع ومواصفات API وخطتي SCM وQA. في الأسبوع الخامس تشغيل المشاريع لدى أعضاء الفريق ونشر الأنظمة، وفي السادس اكتمال التسجيل والدخول والخروج والرئيسية. ثم الميزات والاختبارات، وأخيرًا العرض والبوستر وصفحة تعريف. [المصدر](https://hoblertonschool.notion.site/Portfolio-Project-Meetings-Plan-397204290bfc8077b41fe6333d5b9f16).

لا أستنتج من ذلك أن JWT إلزامي أو أن Temporal إلزامي. الصفحة التقنية تقول خادم قاعدة بيانات حقيقي، ولا تنص وحدها على مزوّد أو موقع جغرافي محدد. النشر مطلب منفصل في خطة الاجتماعات. أي تعليمات إضافية من المدرّبة أو نموذج آخر تُراجع بذاتها؛ لا ننسب لها نصًا لم نتحقق منه.

## مطابقة حاتم الحالي — هذه نتائج قراءة الكود

| الجزء | الموجود في هذه النسخة | ما يحتاجه التنفيذ الدراسي |
|---|---|---|
| الواجهة | React Native + Expo، وشاشة دعوة للمتصفح | تنفيذك المستقل مع Figma ودليل فهم |
| API | مسارات FastAPI مكتوبة ومنطق قرار مستقل | إعادة بنائها وفهمها واستكمال نطاقك المعتمد |
| DB | PostgreSQL حقيقية، groups وmembers وschema_migrations | تصميمك وشرح العلاقات وCRUD ومراجعة بيانات التجارب |
| الحسابات | لا users ولا sessions ولا كلمات مرور | بناء التسجيل والدخول والخروج عبر الطبقات |
| الصلاحيات | مفتاح منظّم ومفتاح عضو مع فحص المجموعة | ربط الصلاحيات بالحسابات إذا اعتمدتِ التصميم الدراسي |
| التجارب | تسع تجارب وهمية في catalog.py | اقتراحي: جدول experiences وseed وقراءة من DB |
| CRUD | إنشاء مجموعة، قراءة وتعديل إعدادات وملفات أعضاء، حذف عضو | لا توجد حاليًا إعادة تسمية مجموعة أو حذفها أو تحرير كتالوج؛ حدديها في نطاقك |
| الاستضافة | PostgreSQL في Docker على الماك، ونفق HTTP مؤقت | نشر قابل للاستخدام وقت التقييم وخطة تشغيل للفريق |
| التوثيق | OpenAPI وهذا الدليل والرسوم | تسليماتك المكتوبة بيدك، لا اعتبار هذا إثباتًا لتأليفك |

اقتراح نقل الكتالوج وإضافة إدارة تجارب هو تصميم مناسب لحاتم لتوسيع حفظ بيانات المشروع وCRUD؛ ليس نصًا يفرض شاشة بعينها من المدرسة. وجود JSONB داخل PostgreSQL تخزين في DB فعلية، ويختلف عن استخدام ملف JSON كقاعدة للتطبيق.

## المكتبات التي نستعملها لا تؤدي المشروع كله نيابة عنا

FastAPI يستقبل HTTP وينظم المسارات؛ نحن نكتب ما يفعله إنشاء المجموعة. psycopg يوصل Python بPostgreSQL؛ نحن نكتب SQL. React يرسم المكونات؛ نحن نكتب الشاشات والتدفقات. OpenAPI يصف المسارات المكتوبة مسبقًا؛ مولّد TypeScript ينتج أنواعًا، ولا ينتج خادم CRUD بدل خادمنا. هذه فروق تقنية؛ اعتماد سياسة الأدوات في المشروع الدراسي يعود للمدرسة.

في مسار «بدون AI» الذي طلبتِه: عطّلي مساعد إكمال الكود التوليدي، واقرئي التوثيق، واكتبي التمارين من فهمك. لا تحتاجين تعطيل TypeScript أو formatter أو debugger؛ هذه أدوات تحقق وتشغيل وليست مؤلفًا لقرارات التطبيق.
