## مثال إعداد عام

[الأسطر 1–4](https://github.com/shathaaa1110-arch/hatim-app/blob/59d45d33cbd6995a07a9b68236dd9de9aaf2b713/.env.example#L1): EXPO_PUBLIC_API_URL تصل إلى JavaScript المبنية، فلا تصلح للأسرار. المثال localhost، و public:test تكتب العنوان العام الحقيقي في .env.local المتجاهلة. الويب يستعمل origin صفحته، ومحاكي iOS يتصل بالماك مباشرة كما يشرح client.ts.

```text
# Physical-device API and invitation origin. Set by npm run public:test.
# The iOS simulator calls http://localhost:8000 directly, independently of this URL.
# Web always calls the API on its current origin.
EXPO_PUBLIC_API_URL=http://localhost:8000
```

## تأكدي من فهمك

اختاري مقطعًا واشرحي مدخلاته ونتيجته وما الذي يغيّره. ثم اكتبي مثالًا أصغر بنفس الفكرة في مجلد تدريب، واذكري ما يجب اختباره قبل دمجه.
