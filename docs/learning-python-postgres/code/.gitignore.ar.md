## ما لا يسجله Git

[الأسطر 1–57](https://github.com/shathaaa1110-arch/hatim-app/blob/59d45d33cbd6995a07a9b68236dd9de9aaf2b713/.gitignore#L1): كل سطر نمط يستبعد ملفات من إضافة Git العادية، و# تبدأ تعليقًا. النمط .env*.local يتجاهل ملفات الإعداد المحلية، ولا يطابق ملفات .env.example فتظل قابلة للتتبع. الحزم والمشاريع المولدة و dist وبيانات DB والنسخ الاحتياطية ومخرجات التشغيل لا تدخل المستودع. تجاهل ملف لا يحذفه ولا يزيل نسخة سبق تسجيلها في Git؛ هذه قواعد إضافة وليست تشفيرًا.

## تأكدي من فهمك

اختاري مقطعًا واشرحي مدخلاته ونتيجته وما الذي يغيّره. ثم اكتبي مثالًا أصغر بنفس الفكرة في مجلد تدريب، واذكري ما يجب اختباره قبل دمجه.
