## المتطلبات التي تهم اختيارك

المدرسة تسمح بـ.NET وبأطر الواجهات وباستضافة البنية التحتية، وتطلب أن يبني الطالب قاعدة البيانات وتصميمها وواجهة API ومنطقها والواجهة التي تستهلكها. المطلوب يشمل التحقق من المدخلات، الأخطاء، CRUD، توثيق endpoints، ومصادقة يملك الخادم منطقها. خدمات توليد الباك إند أو تولّي المصادقة الأساسية بدل الطالب ممنوعة. استخدام قاعدة مستضافة فقط يختلف عن تفويض الـAPI والمصادقة إلى منصة جاهزة. [المتطلبات التقنية](https://hoblertonschool.notion.site/Portfolio-Project-Technical-Requirements-311204290bfc8076ac82d9867899af46).

الصفحة تسمح بمساعدة AI في الأفكار وموكابات الواجهة، وتطلب تنفيذ الواجهة بنفسك مع التصميم في Figma. هذا الإذن المحدود لا يعني أن توليد كود المشروع وتسليمه بوصفه عملك مسموح. هدف هذا الدليل هو الفهم؛ سجّل التعلّم والتطبيق المستقل لا يعوّضه حفظ شرح كود جاهز. [المتطلبات التقنية](https://hoblertonschool.notion.site/Portfolio-Project-Technical-Requirements-311204290bfc8076ac82d9867899af46).

## مقارنة بالكود الحالي

العمود الأوسط أدناه نتيجة قراءة المستودع، وليس وصفًا لنسخة مستقبلية مكتملة.

| الموضوع | النسخة الحالية | ما تبنينه للتسليم |
|---|---|---|
| واجهة تتصل بخادمك | React Native + Expo، ومتصفح للأعضاء | أعيدي تنفيذ رحلاتك وتصميمك بنفسك |
| خادم ومنطق عمل | ASP.NET Core controllers + Planner | افهمي واكتبي endpoints والقواعد بنفسك |
| قاعدة بيانات فعلية | SQLite على الماك، تحفظ المجموعات والأعضاء | قاعدة على خادم مثل PostgreSQL أو SQL Server؛ SQLite محلية مضمّنة لا تحقق وصف DB server وحدها |
| مخطط البيانات | جدولان؛ التفضيلات والإعدادات JSON داخل أعمدة TEXT | صمّمي علاقات تناسب الاستعلامات، واكتبي schema scripts أو migrations |
| تهيئة المخطط | `CREATE TABLE IF NOT EXISTS` و`user_version=1` | نظام واضح لتغييرات المخطط؛ الكود الحالي لا ينفّذ سلسلة ترحيلات مستقبلية |
| حسابات المستخدمين | لا يوجد بريد/كلمة مرور/صفحة حساب | تسجيل حساب ودخول وخروج حسب خطة المدرسة |
| التفويض | مفتاح خاص للمنظّم ومفتاح لكل عضو | اربطي حساباتك بصلاحيات المجموعات، واختبري منع الوصول غير المسموح |
| كلمات المرور | لا توجد كلمات مرور في هذه النسخة | عند اعتمادها، استخدمي مكتبة مناسبة لتجزئتها؛ SHA-256 المستخدم هنا للمفاتيح العشوائية ليس حل كلمات مرور |
| الكتالوج | تسع تجارب وهمية في JSON | خزّني بيانات المنتج في DB وصمّمي إدارة المحتوى إذا كانت ضمن نطاقك |
| عمليات CRUD | إنشاء مجموعة وعضو، قراءة، تحديث إعدادات/تفضيلات، حذف عضو | وثّقي CRUD المطلوب لكيانات مشروعك؛ لا يوجد CRUD كامل لكل كيان هنا |
| توثيق API | ملف OpenAPI حقيقي + أنواع TS مولّدة | أضيفي أمثلة الأخطاء والصلاحيات وتوثيقًا يناسب تسليمك |
| الاختبارات | اختبارات C# وتكامل واختبارات متصفح | اكتبي اختباراتك من القواعد قبل اعتبار الشاشة دليل نجاح |
| التصميم | تنسيقات في TSX وصور | ملف Figma وتدفقات المستخدم؛ الكود ليس بديلًا عن تسليم Figma |
| النشر | Quick Tunnel مؤقت مرتبط بالماك | نشر يمكن للفريق والمقيّم الاعتماد عليه مع DB مستضافة |
| التخطيط والتوثيق | README ودليل النقل | user stories، ERD، sequence، قرارات التقنية، خطة Git وQA وسجل تعلم فعلي |

دخول عضو برابط، واسترجاعه بمفتاح محفوظ، ليس هو رحلة signup/login/logout المطلوبة في خطة الاجتماعات. يمكن الاحتفاظ بفكرة الضيوف لاحقًا، مع حسابات حقيقية للمنظمين، إذا وافق نطاق مشروعك. [خطة الاجتماعات](https://hoblertonschool.notion.site/Portfolio-Project-Meetings-Plan-397204290bfc8077b41fe6333d5b9f16).

## ما الذي لا تحتاجينه لمجرد أن المشروع حديث؟

لا يوجد اشتراط ظاهر لـJWT تحديدًا؛ المصدر يذكر جلسات أو JWT. ولا يوجد اشتراط لـTemporal أو microservices أو Docker أو Liquid Glass. أمثلة الدفع والتنبيهات في الخطة لا تجعل الدفع وظيفة إلزامية لتطبيق أكل. اختاري أبسط وسيلة تحقق تدفقك ويمكنك تفسيرها. السماح بـORM يعني إمكان استعماله، مع بقاء فهم المخطط والاستعلامات مسؤوليتك. [المتطلبات التقنية](https://hoblertonschool.notion.site/Portfolio-Project-Technical-Requirements-311204290bfc8076ac82d9867899af46).

## ترتيب التسليم الزمني

الخطة المنشورة مدتها ١٢ أسبوعًا: أسبوع للفريق والأفكار، أسبوع للـcharter، أسبوعان للتوثيق، ستة للـMVP، وأسبوعان للإغلاق. في بداية التطوير يجب تشغيل الأنظمة لكل عضو ونشرها، وفي الأسبوع التالي إنجاز المصادقة والرئيسية. ثم تُنجز الوظيفة الأساسية، الوظائف الثانوية، والاختبارات، وتأتي مواد العرض في النهاية. الموكابات في Figma، ومعها مخططات البنية والبيانات والتفاعلات ومواصفات API وخطط إدارة المصدر والجودة. [خطة الاجتماعات](https://hoblertonschool.notion.site/Portfolio-Project-Meetings-Plan-397204290bfc8077b41fe6333d5b9f16).
