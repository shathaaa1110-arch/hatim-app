# PDF fonts

Unmodified IBM Plex Sans Arabic Regular (400) and SemiBold (600), copied from
`@expo-google-fonts/ibm-plex-sans-arabic` version `0.4.2` already used by Hatim.
`LICENSE.txt` is the package's `LICENSE_FONT` (SIL Open Font License 1.1).

These server-owned copies let the Python renderer run offline and embed the
font subsets in PDFs. Docker copies them with the `hatim` package; Node and
Expo are not required at PDF request time.
